# Coding-lab_Group24

## Project Overview

This project implements a secure, permission-governed data pipeline for
Kenyatta National Hospital (KNH)'s Digital Infrastructure. It manages live
sensor data (Heart Rate, Temperature, and Water Usage) generated by a Python
simulation engine (`hospital_system.py`), using a set of Bash shell scripts
to initialize the environment, secure sensitive logs, analyze critical
events, and archive processed data.

## Setup Instructions

1. **Start the data simulator:**
```bash
   python3 hospital_system.py start
```

2. **Run the admin script** (sets up directories and secures permissions):
```bash
   ./hospital_admin.sh
```

3. **Run the analysis script** (extracts critical alerts and audits water usage):
```bash
   ./hospital_analysis.sh
```

4. **Run the archive script** (rotates logs into `archived_logs/`):
```bash
   ./hospital_archive.sh
```

5. **Stop the data simulator when finished:**
```bash
   python3 hospital_system.py stop
```

## Repository Structure

- `hospital_system.py` — Core data simulation engine
- `hospital_admin.sh` — Initializes directories and secures permissions
- `hospital_analysis.sh` — Analyzes critical vitals and water usage
- `hospital_archive.sh` — Archives and rotates log files
- `.gitignore` — Excludes generated logs and reports from version control
- `README.md` — This file

## Notes

Per KNH data policy, `active_logs/`, `archived_logs/`, and `reports/` are
excluded from version control via `.gitignore` to prevent uploading
sensitive patient data to GitHub.
